
# 🔒 Convite Especial — Operação Aniversário

Projeto de convite digital interativo desenvolvido para uma comemoração de aniversário, utilizando uma temática de operação confidencial.

A experiência foi criada para surpreender a convidada por meio de uma sequência de telas interativas, desde a abertura de uma correspondência até a apresentação da convocação oficial.

## 🎯 Sobre o projeto

O projeto simula uma comunicação confidencial dividida em três etapas:

1. **Correspondência:** tela inicial com acesso à mensagem secreta.
2. **Termos da missão:** apresentação das condições para aceitar a convocação.
3. **Convite oficial:** apresentação dos detalhes do evento e confirmação de presença pelo WhatsApp.

## 🚀 Funcionalidades

- Interface interativa com três etapas.
- Navegação entre telas sem recarregar a página.
- Animações de transição.
- Contagem regressiva para o evento.
- Confirmação de presença via WhatsApp.
- Reprodução de música com controle de áudio.
- Layout responsivo para dispositivos móveis e computadores.
